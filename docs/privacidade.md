# Política de privacidade da Própons IA

*Última atualização: 25 de setembro de 2026*

A Própons IA é um aplicativo de estudos gratuito e de código aberto. A inteligência artificial roda **dentro do seu aparelho**. Não existe conta, login nem servidor da Própons.

## O que fica no seu aparelho

- **Conversas, anexos, memória, Conhecimento, flashcards e ajustes** ficam guardados só no seu aparelho. Nada disso é enviado para ninguém.
- **Fotos, arquivos e áudios** que você manda para a IA são lidos e transcritos no próprio aparelho.
- **Microfone:** é usado só quando você toca para gravar. A transcrição acontece no aparelho.
- **Câmera:** é usada só quando você escolhe tirar uma foto para a IA ler.
- **Localização:** é pedida pelo sistema só quando você pergunta algo sobre onde está, como o clima ou a hora "aqui".

## Quando o app usa a internet

- **Baixar o app, os modelos de IA e as vozes de transcrição.** Esses downloads vêm do GitHub e do Hugging Face.
- **Pesquisa na internet**, só se você ligar essa opção. Nesse caso, a sua pergunta vai para o buscador DuckDuckGo, e as páginas dos resultados são abertas para a IA ler.
- **Lugar, hora e clima.** Em perguntas desse tipo, o app envia só o nome da cidade ou as coordenadas:
  - para o serviço de previsão Open-Meteo;
  - para o BigDataCloud, que dá o nome do lugar;
  - para o ipwho.is, quando é preciso estimar a posição aproximada pela conexão.

  Dá para desligar isso em Ajustes → Respostas.
- **Ícones dos sites** que aparecem nas fontes de uma pesquisa, buscados no serviço de ícones do DuckDuckGo.
- **Procurar atualizações:** o app consulta a última versão publicada no GitHub. Na versão da Microsoft Store, quem cuida das atualizações é a própria Store.

## O que a Própons não faz

- Não coleta dados pessoais.
- Não usa rastreadores, anúncios nem análise de uso.
- Não vende nem compartilha dados.

## Apagar os seus dados

Em Ajustes → Conversas → Apagar todas as conversas, e em Ajustes → Memória. Desinstalar o app apaga o que ele guardou.
